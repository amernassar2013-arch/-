# اكتشف الأردن | Discover Jordan (PixelSite 2.0)
تطبيق ويب بيخطط رحلتك في الأردن بالذكاء الاصطناعي. بتدخل اهتماماتك، وبيطلع لك برنامج يوم بيوم بأماكن حقيقية من الأردن.

مصمّم بألوان مستوحاة من الهوية الأردنية، ليعكس روح البلد من أول نظرة.

مشروع مشارك في مسابقة **PixelSite 2.0 — Reimagining Jordanian Tourism**.

## الفكرة

السياحة في الأردن غنية، بس التخطيط لرحلة بيتطلب بحث طويل بين مواقع وآراء متفرقة، سواء كنت سائح أجنبي أو أردني بدك تسافر داخل بلدك. "اكتشف الأردن" بيختصر هاد كله: بتختار اهتماماتك، وبتاخد خطة جاهزة.

**المستخدمين المستهدفين:** السياح الأجانب، والأردنيين بالرحلات الداخلية.

## المميزات

- تخطيط رحلة يوم بيوم حسب اهتمامات المستخدم باستخدام الذكاء الاصطناعي
- مخطط محلي احتياطي بيشتغل تلقائياً إذا ما توفر الـ AI، فالموقع ما بيتعطل
- زر **"اكتشفت هاد المكان"** مع عدّاد للأماكن المكتشفة ونجوم ندرة (محفوظ في localStorage)
- دعم لغات متعددة: العربية، الإنجليزية، الإيطالية
- تصميم بهوية أردنية: ألوان مستوحاة من الطابع المحلي للأردن

## التقنيات المستخدمة

- HTML / CSS / JavaScript
- Firebase (مستورد عن طريق روابط URL)
- Claude API لتوليد الخطط
- `places.json` كقاعدة بيانات للأماكن

## كيف تشغّله

1. حمّل المشروع: **Code ← Download ZIP**، وفك الضغط.
   (أو: `git clone https://github.com/amernassar2013-arch/-Discover-Jordan-Competition`)
2. ضع ملف `config.js` داخل المجلد: `advnace/js`
   (الملف فيه مفتاح الـ AI، فما انرفع على GitHub لأسباب أمنية، وتم إرفاقه مع التسليم.)
3. افتح مجلد `advnace` بـ **VS Code**، وشغّل `index.html` بـ **Live Server**.
   ⚠️ لا تفتحه بالضغط المزدوج.

**ملاحظة:** بدون ملف `config.js` بيشتغل المخطط المحلي تلقائياً. ومع الملف بيشتغل مخطط الرحلات بالذكاء الاصطناعي.

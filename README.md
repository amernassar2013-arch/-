# اكتشف الأردن | Discover Jordan (PixelSite 2.0)

موقع سياحي تفاعلي لاكتشاف الأردن: مخطط رحلات ذكي، واكتشاف الأماكن حسب ندرتها (من 1 إلى 5 نجوم)، بثلاث لغات (العربية، English، Italiano).

An interactive tourism website to discover Jordan: a smart trip planner, and a place-discovery system rated by rarity (1 to 5 stars), in 3 languages.

## المميزات | Features
- مناطق استكشاف مرتبة من 5 نجوم إلى 1 نجمة
- صفحة لكل مكان فيها صور ونبذة
- فتح المواقع في تطبيق الخرائط
- ثلاث لغات: العربية، English، Italiano

## التقنيات | Tech Stack
HTML, CSS, JavaScript, Firebase, Node.js (Express)
